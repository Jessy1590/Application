Import / export CSV

Fusion d’entités

Réaffecter les fiches vers la valeur conservée, puis désactiver la source. Tous les types d’entités.

Les niveaux connus des deux valeurs sont unis sur la valeur conservée.

Doublons exacts (valeur_norm)

Paires actives avec la même valeur_norm pour le type sélectionné. Pas de fusion sémantique automatique.
